# codex-skills

Codex skills collection for reusable AI workflows.

## Skills

### nn-ui-figma-restoration

用于根据 Figma 地址和截图进行 UI 一比一还原，包含 NN 基础组件库匹配、`@nn/ui` 组件映射、当前模块风格检查、Chrome 自动截图对比、设计注释/动效/特效、复杂图层图片溯源和字体检查。

安装方式：

```text
使用 skill-installer 安装：
https://github.com/azsxshitao/codex-skills/tree/main/skills/nn-ui-figma-restoration
```

安装后重启 Codex，然后可以这样使用：

```text
在对话框中输入/，然后选择安装nn-ui-figma-restoration即可
```
